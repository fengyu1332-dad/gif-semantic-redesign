# GIF Semantic Redesign · GIF 贴图语义重设计

从原 GIF 的核心含义出发，重新设计画风、鲜艳配色、动作与表情，制作透明循环贴图。

## 功能

- 分析原动画的情绪、用途、动作节拍、文字和箭头方向。
- 支持单个小样、随机 N 款、处理全部剩余素材和历史覆盖核查。
- 按原图 SHA-256 去重，兼容缺少哈希的早期制作记录。
- 为每款设计不同于原图的常用贴图风格，如软陶、果冻、折纸、毛绒、像素和水彩。
- 生成透明姿态图集，再合成带关键姿态变化的循环 GIF。
- 验证透明边缘、帧数、时长、循环、成品覆盖和压缩包完整性。
- 输出原图/新版对照页、总览、提示词、来源清单和质检报告。

## 安装

将本仓库目录复制到 `~/.codex/skills/gif-semantic-redesign/`，确保其中包含 `SKILL.md`，然后重新开启 Codex 会话。Windows 常用位置为 `%USERPROFILE%\.codex\skills\gif-semantic-redesign\`。

## 使用示例

```text
使用 $gif-semantic-redesign，分析这个 GIF 的核心含义，换成不同的常见贴图风格，配色鲜艳，并重新设计动作，输出透明动态 GIF。
```

```text
使用 $gif-semantic-redesign，从指定 GIF 文件夹随机选择 20 个没做过新版的动态素材，完成重设计、质检与集中归档。
```

```text
使用 $gif-semantic-redesign，核查文件夹中的动态 GIF 是否都有对应新版，按内容哈希去重，并列出缺失成品。
```

## 工作流程

选源和历史去重 → 原图拆帧分析 → 核心含义与新动作设计 → 透明图集生成 → 动画合成 → 自动检查与视觉验收 → 对照页和测试包交付。

默认可输出 512px 与 256px 两套；数量、尺寸、背景和风格以用户请求为准。

## 运行条件与边界

本仓库提供 Codex 工作流指令，不是独立 GIF 生成软件。执行生成任务需要可用的图像生成工具；本地拆帧、编码和检查可使用 Python/Pillow 或 FFmpeg。实际权限、费用与可用模型取决于执行环境。

单帧 GIF 会单独统计；需要用户要求动态化后再设计动画。自动检查不能替代对文字、方向、姿态和风格差异的视觉验收。请仅处理有权使用的素材。
